# 交互式 2D 分形

用 WebGL 2.0 画的 Sierpinski 垫片，两种生成方式（混沌游戏、递归细分），带一套参数和交互控制。

## 运行



## 文件

- `index.html` — 页面、着色器、样式
- `src/geometry.js` — 生成顶点数据：正 n 边形、混沌游戏、递归细分
- `src/interaction.js` — 鼠标和键盘
- `src/ui.js` — 左边的参数面板
- `src/main.js` — WebGL 初始化、把数据传给 GPU、渲染循环

## 两种算法

**混沌游戏**：先在外接圆心放置一个点，然后每次随机挑一个顶点，让当前点朝它走一段固定比例，走个几万次点即可落成垫片。比例取 1/2、顶点取三角形三个角的时候，即 `p = (p + 随机顶点) / 2`。点一定落在图形内部，不用额外裁剪。

**递归细分**：`subdivide(triangle, depth)` 将三角形按三边中点切成角上的三个，中间三角舍弃掉，再对三个小三角形递归下去。深度 d 得到 3^d 个三角形，限制到 6（729 个）。同一份顶点数据只需换图元就可以在点云 / 线框 / 实体之间切换。

## 操作

| 操作 | 效果 |
|---|---|
| 左键拖动 | 平移 |
| 滚轮 | 缩放 |
| 按 1 / 2 / 3 | 切点云 / 线框 / 实体 |
| 按空格 | 暂停或继续逐点生长 |
| 顶点数滑条 | 混沌游戏撒多少个点（只有点云模式） |
| 边数 n 滑条 | 3 到 8 边形，见下面 E1（只有点云模式） |
| 递归深度滑条 | 0 到 6（只有线框和实体模式） |
| 点大小 / 配色 | 调整点的大小和颜色 |

生长动画的做法是每帧把进度往前推一点，进度乘总顶点数等于该帧要画多少个顶点，三种模式下都只画完整的图元。

## E1：n 边形垫片

边数滑条能画出五边形、六边形这些垫片。收缩比取 `1 / (1 + 2cos(π/n))`，n=3 时刚好是 0.5，n=5 时是 0.382，能对上标准的五边形垫片。

奇数 n（3、5、7）拼得刚好，图形是连成一片的；偶数如n=4 中间会留缝、点变得很散，n=6 和 8 会有一点重叠、图形发实。这是"朝顶点收缩"这种画法本身的限制。

## 其他

- 2D 只有平移和缩放，直接在顶点着色器里用两个 uniform 做。
- 拖顶点数滑条时图形会重新更新一下，因为参数一变就重新随机撒点，属于算法本身的随机性。
- 着色器加载用的是配套的 `Common/initShaders.js`。
